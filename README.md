# 🔗 URL Shortener Service

A full-stack URL Shortener application that converts long URLs into short, shareable links. Built with a modern web stack and serverless backend architecture.

## 🚀 Features

* Generate short URLs from long links
* Redirect users to original URLs
* Unique and fast URL generation
* Persistent storage using MongoDB
* Serverless backend deployment using AWS Lambda
* Clean and responsive UI

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Database: MongoDB
* Cloud: AWS Lambda (serverless functions)

## ⚙️ How It Works

1. User enters a long URL
2. Backend generates a unique short ID
3. URL is stored in MongoDB
4. Short link is returned to the user
5. Visiting the short link redirects to the original URL

## 🌐 Future Improvements

* Analytics (click tracking)
* Custom short URLs
* Expiry links
* User authentication

## 📌 Project Goal

To understand backend architecture, database design, and serverless deployment by building a real-world application.
